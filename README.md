# Test i international økonomi

En interaktiv øveside til test i international økonomi / samfundsøkonomi på hhx-niveau.
Alt ligger i én fil (`index.html`) – ingen installation, ingen afhængigheder.

## Funktioner

- **Flashcards** – vend kortet og se et kort modelsvar. Vælg "Kunne det" eller "Øv igen".
- **Quiz** – skriv dit eget svar, tryk "Tjek" og sammenlign med modelsvaret.
- **Gentagelse** – spørgsmål markeret "Øv igen" kommer tilbage efter ca. 3 kort, indtil du kan dem.
- **Fremskridt** – bjælke over hvor mange af de 50 du kan; gemmes i browseren (localStorage).
- **Emnefilter** – Konjunkturer, Økonomiske mål og BNP, Efterspørgsel og udbud, Arbejdsmarked, Offentlig sektor og skat, Velfærd og fremtid.
- **Bland** – tilfældig rækkefølge.
- Virker på mobil og understøtter mørk tilstand.

Genveje på computer: `Mellemrum` vend kort · `1` Kunne det · `2` Øv igen · `Ctrl/⌘ + Enter` tjek svar.

## Brug

Åbn `index.html` i en browser – eller udgiv den med GitHub Pages:

1. Upload `index.html` og `README.md` til et repository på GitHub.
2. Gå til **Settings → Pages**.
3. Under **Build and deployment** vælg **Deploy from a branch**, branch `main` og mappe `/ (root)`, og tryk **Save**.
4. Efter et minut eller to ligger siden på `https://<dit-brugernavn>.github.io/<repository-navn>/`.

## Bemærk

Modelsvarene er korte og skrevet ud fra almindeligt hhx-pensum. Hvor svaret afhænger af aktuelle tal eller regler
(fx ledighedsprocent og skattesystemet efter skattereformen 2026), står der en note om at tjekke det i dit undervisningsmateriale.

Fremskridt gemmes kun i den browser, du bruger, og følger ikke med mellem enheder.
